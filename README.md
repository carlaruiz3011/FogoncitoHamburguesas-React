# Fogoncito Hamburguesería 🍔🔥

Reconstrucción del sitio web de la hamburguesería Fogoncito, migrado a React como parte de la Ejercitación 4.1.

## Integrantes
* Carla Ruiz
* Maria Luz Valli
* Guadalupe Perez

## Descripción
La aplicación cuenta con navegación entre tres pantallas principales (Inicio/Promociones, Menú y Carrito). Incluye filtros de búsqueda, selección de cantidad, un carrito interactivo con barra flotante y un formulario de envío con validación de datos. Los productos se cargan desde un archivo JSON externo utilizando `useEffect` y `fetch`.

## Tecnologías utilizadas
* React (Vite)
* Hooks (useState, useEffect)
* CSS3 puro (Variables, Flexbox, Grid)
